## Overview
This assignment contains 10 Python programming experiments focused on practical, activity-based problem solving. Each experiment includes an aim, concepts covered, algorithm and logic, test conditions, Python source code, and sample execution output.

## Experiments
1. **Campus Resource Allocation Under Constraints** — Uses nested lists, tuple unpacking, dictionaries, loops, priority-based allocation, and shortage calculation.
2. **Student Academic Risk Classification** — Uses lists, parallel data, nested conditions, risk-factor collection, and classification.
3. **Retail Order Dispatch and Return Analysis** — Uses dictionaries, loops, arithmetic, inventory updates, and record validation.
4. **Energy Conservation Before-and-After Analysis** — Calculates energy savings and percentages, then ranks appliances.
5. **Nested List Sports Performance Analysis** — Calculates totals, averages, score ranges, trends, and rankings with tie-breakers.
6. **Multi-Stage Scholarship Shortlisting** — Filters scholarship candidates by eligibility conditions and selects candidates within a quota.
7. **Integrated University Fee and Eligibility Audit** — Checks fee payments, attendance, internal marks, and eligibility conditions.
8. **Smart Hostel Resource Monitoring** — Calculates utility charges, checks consumption thresholds, and aggregates floor-wise usage.
9. **Multi-Route Courier Dispatch Planning** — Allocates packages according to route zones, priorities, and vehicle capacities.
10. **Campus Festival Registration and Financial Audit** — Detects duplicate registrations and calculates registration income and the final balance.

## How to Run
1. Install Python 3 if it is not already installed.
2. Copy the source code for the experiment you want to run into a `.py` file (or save each experiment as its own file).
3. Open a terminal or command prompt in the folder containing the file.
4. Run the program with:

   ```bash
   python filename.py
   ```

   On some systems, use `python3 filename.py`.

5. Compare the output with the sample output shown for that experiment in the assignment PDF.
